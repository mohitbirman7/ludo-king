# 👑 Ludo King — Authentic Board Game & Real-Time Admin Controller

A complete, high-performance web and PWA recreation of **Ludo King**, featuring:
- **Instant Zero-Delay 3D Dice Engine** (tumble begins on touch with concurrent resolution).
- **Authentic 12-Second Circular Turn Timer** with warning audio ticks and auto-roll fallback.
- **Realistic 3D Pawns (Gotis)** with parabolic hopping jumps and authentic step sounds.
- **Capture Impact & Signature Snake Rewind** with celebration bonus roll banners.
- **Real-Time Admin Control Panel** (`/admin/dashboard.php`) with live telemetry and one-tap dice overrides.
- **Secret In-Game Cheat Bar** (press `'A'` or triple-tap top logo).
- **Multiplayer Support**: Local Pass N Play & Online 6-Digit Room Codes.
- **PWA Ready**: Installable on Android, iOS, Windows, and macOS.

## Quick Start (XAMPP)
1. Start Apache in XAMPP.
2. Open `http://localhost/ludo-king-main/index.php`.
3. Open Admin Panel: `http://localhost/ludo-king-main/admin/dashboard.php` (Login: `admin` / `mohit@1760`).
4. Read `PROJECT_DOCUMENTATION.md` for full technical project report and viva presentation guidelines.
